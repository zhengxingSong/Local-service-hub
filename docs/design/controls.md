# 服务中枢 — 控件与可用条件（按钮级）

> 上游：[surfaces.md](surfaces.md)（面）、[concepts.md](concepts.md)（概念）。
> 本文把每个面的元素列到控件级，重点是**可用条件**：每个控件在什么状态下可点、禁用时给出什么理由。
> 规格写成"条件 → 行为 → 反馈"，因为状态位多（`enabled` / `autostart` / `prepared` / `state` / 组 `n/m`），
> 不写清条件，实现时必然退化成一堆散落的 if。

## 0. 三条通用规则

1. **禁用必给理由。** 任何禁用态的控件都要能回答"为什么不能点"（tooltip 或行内小字）。静默禁用是不允许的——它就是"找不到重点"的另一种形态。
2. **危险动作必须说明后果。** 删除服务（移除配置 + 停进程）、删除组（**只解散，不删服务**）、强制停止（可能留下孤儿进程）、快照回滚（会覆盖当前配置）——四种文案各不相同，不能共用"确定吗"。
3. **动作结果走 Toast，状态就地更新。** 不用"重新加载"表达成功；长动作（准备/下载/切换）用内联进度，不用模态。

## 1. 运行态

### 1.1 B1 用途卡（每张卡的控件相同）

| 元素 | 类型 | 可用条件 | 行为 | 反馈 |
|---|---|---|---|---|
| 组名 | 文本（可点） | 恒可用 | 就地展开成员明细（B3） | 卡内展开 |
| 可用性徽标 | 状态 | — | — | 由 `n/m` 与失败数决定：`可用` / `部分可用 n/m` / `切换中` / `未运行` |
| 就绪计数 `n/m` | 文本 | 展开后可见 | — | 随成员状态实时更新 |
| 独占标记 | 图标 + tooltip | 仅当标记独占 | 悬停显示"与哪些独占组互斥" | tooltip |
| 随应用启动 | 开关 | 组成员 ≥1 | 切换即保存 | Toast；失败则回滚开关 |
| **主按钮** | 按钮 | 见下方状态映射 | 启用 / 停用 / 中止切换 | 就地进入切换进度（B5） |
| 溢出菜单 · 重启整组 | 菜单项 | 状态为 `可用` 或 `部分可用` | 逆序停 → 顺序起 | 就地进度 + Toast |
| 溢出菜单 · 编辑组 | 菜单项 | 恒可用 | 打开组定义（A3） | 进配置态 |
| 溢出菜单 · 删除组 | 菜单项（危险） | 恒可用 | 确认模态 | Toast；文案须写明"只解散，不删服务" |
| 异常区 | 内联块 | 仅当存在失败成员 | 点「处置」就地展开处置层（C1–C4） | 就地展开 |
| 进度区 | 内联块 | 仅当切换中 | 「中止并回滚」按钮 | 就地阶段文本 + 进度 |

**主按钮的状态映射**（这是整张卡的核心，条件必须穷举）：

| 组状态 | 主按钮 | 可用条件 | 点击后 |
|---|---|---|---|
| 未运行 | **启用** | 至少一个成员 `enabled=true` 且 `prepared`；否则禁用并提示"X 未准备" | 走预检 → 通过则启动（B5）；不通过则展开 B4 |
| 可用 / 部分可用 | **停用** | 恒可用 | 逆序停止全部成员；提示共用的服务（若被其它运行中的组引用） |
| 切换中 | **中止并回滚** | 恒可用 | 中止当前切换，恢复被让位的组 |
| 全部成员被禁用 | **启用**（禁用） | — | 提示"组内服务全部被禁用，请先在配置中启用" |

### 1.2 B2 资源面

| 元素 | 类型 | 可用条件 | 行为 | 反馈 |
|---|---|---|---|---|
| 资源行 ×4（显存/RAM/CPU/磁盘） | 数值 + 条 | 恒可见 | — | 超阈值变色；磁盘按盘分别显示 |
| 「可启动清单」 | 文本 | 有可用余量时 | 点某一项跳到该服务的启用 | 静态列出"按当前余量可启动：X / Y" |
| 占用者列表（可折叠） | 列表 | 有占用者时 | 每行：「停止」+ 点名称进详情 | 停止前确认；停止后余量即时变化 |
| 占用值来源标注 | 徽标 | 恒有 | tooltip 解释 | `实测` / `估算` / `声明` 三种，不可混用同一视觉 |
| 无法采样提示 | 内联条 | nvidia-smi 不可用时 | 「打开设置」 | 明确说"显存数据不可用"，不要显示 0 |

### 1.3 B3 成员明细（就地展开）

| 元素 | 类型 | 可用条件 | 行为 | 反馈 |
|---|---|---|---|---|
| 状态点 + 服务名 | 文本（可点） | 恒可用 | 打开抽屉（默认"运行"页） | 抽屉 |
| 状态位 | 徽标组 | 恒可见 | tooltip | `已禁用` / `未准备` / `运行中` / `就绪中` / `失败` / `已停止` |
| 端口 | 文本 | 有端口时 | 可复制 | — |
| 就绪判定结果 | 文本 | 状态为运行中 | tooltip 显示判定方式 | `已就绪` / `就绪中…` / `未通过` |
| 实测资源 | 数值 | 有实测值 | tooltip 显示时间 | 无实测时显示估算并标注 |
| 主操作 | 按钮 | 未准备 → 「准备」；已停止 → 「启动」；运行中 → 「停止」 | 见条件 | 就地状态变化 |
| 重启 | 按钮 | 状态为运行中 / 失败 | 停 → 起 | 就地 |
| 详情 / 日志 | 按钮 | 恒可用 | 打开抽屉（运行页） | 抽屉 |

### 1.4 B4 预检面（模态，**仅在不通过时出现**）

| 元素 | 类型 | 可用条件 | 行为 | 反馈 |
|---|---|---|---|---|
| 标题 | 文本 | — | — | 「无法启动「X」」或「需要先处理 N 项」 |
| 四族分区 | 分区 | 恒有（无问题的族折起为一行"✓ 无问题"） | — | 顺序固定：依赖 → 环境 → 占用 → 资源 |
| 每族结论行 | 文本 | — | — | 「需要 embedding 已就绪，当前未启动」这类**可判断**的句子，不是错误码 |
| 每族动作 | 按钮 ×1–3 | 按族不同（见下） | 见下 | 修一项即**就地重新预检**该区 |
| 依赖族动作 | 「按序启动依赖」 | 存在未就绪依赖 | 转入该依赖的启动流程 | 就地显示依赖就绪进度 |
| 环境族动作 | 「安装 / 拉取 / 定位」+「打开设置」 | 存在缺失项 | 执行对应准备动作；定位=打开文件选择 | 就地显示准备进度 |
| 占用族动作 | 「停掉它」+「换端口」 | 端口被占 / 互斥组在跑 | 停 = 确认后停占用者；换端口 = 填入建议端口 | 就地重新预检 |
| 资源族动作 | 「释放」+「降需」 | 需求 > 余量 | 释放 = 列出候选与可释放量；降需 = 给出建议参数值并一键写入 | 就地重新预检；差值随之下调 |
| 强制启动 | 按钮（次要） | 至少有一族不通过 | 直接进入启动 | Toast 说明"已按降级启动"；结果写入运行记录 |
| 取消 | 按钮 | 恒可用 | 关闭，不启动 | — |

### 1.5 B5 切换进度（就地）

| 元素 | 类型 | 可用条件 | 行为 | 反馈 |
|---|---|---|---|---|
| 阶段列表 | 列表 | 切换中 | — | 停止 X → 等端口释放 → 启动 Y → 等就绪 `n/m` |
| 中止并回滚 | 按钮 | 停止/启动阶段 | 中止并恢复被让位的组 | 就地显示回滚过程 |
| 失败结论 | 内联块 | 回滚完成后 | 「处置」展开归因 | 说明"新档启动失败，已恢复 X 组" |

## 2. 配置态

### 2.1 A1 服务清单

| 元素 | 类型 | 可用条件 | 行为 | 反馈 |
|---|---|---|---|---|
| 新建服务 | 主按钮 | 恒可用 | 第一步：探测（选目录 / 选文件 / 粘贴命令）→ 给出形态建议 | 进详情（定义页） |
| 搜索框 | 输入 | 服务数 > 3 | 按名称/端口/别名过滤 | 就地过滤 |
| 过滤 | 分段控件 | 恒可用 | 按形态（全部/docker/源码/模型）、按状态（全部/已启用/已禁用/未准备） | 就地过滤 |
| 行 · 名称 | 文本（可点） | 恒可用 | 打开抽屉（默认"定义"页） | 抽屉 |
| 行 · 形态徽标 | 徽标 | 恒可见 | — | `docker 应用` / `源代码部署` / `模型服务` |
| 行 · 暴露 | 文本 | 有端口或 alias | 可复制 | — |
| 行 · 归属组 | 徽标（可点） | 恒可见 | 点开查看该组 | 显示 `未分组` 也算合法状态 |
| 行 · 状态徽标 | 徽标组 | 恒可见 | tooltip | `已启用/已禁用` · `已准备/未准备/准备失败` · `最近成功/最近失败/从未运行` |
| 行 · 溢出菜单 | 菜单 | 恒可用 | 编辑 / 复制 / 删除 / 准备 / 试运行 / 运行记录 / 打开所在目录 / 导出 / 加入组 | 各动作 Toast |
| 空态 | 空状态块 | 服务数 = 0 | 「新建服务」 | 说明三类形态各适合什么 |

> 行内**不放**启用/自启开关——它们是策略，改动有副作用（影响组与自启），放在详情页更安全，也让清单保持"定义视角"。

### 2.2 A2 服务详情（抽屉：定义页 / 运行页）

**定义页 — 六段**

| 段 | 控件 | 可用条件 | 行为 |
|---|---|---|---|
| 形态 | 三选一 | 新建时由探测预选；已保存的服务改形态需确认（会清空不兼容字段） | 切换字段区 |
| 准备 | compose：「拉取镜像」「构建」「强制重建」；source：【准备命令】输入 + 超时；model：「选择素材」/「下载」+ 校验状态 | 形态匹配 | 可单独执行；幂等；可取消 |
| 启动 | compose：目录/文件/profiles/环境变量；source：可执行文件/参数/工作目录/环境变量；model：runtime/模型/mmproj/参数面板 | 形态匹配 | — |
| 暴露与就绪 | 端口 + 就绪判定（不检查/端口/HTTP/模型列表）+ 条件字段 | 恒可用 | 判定方式改动后提示"下次启动生效" |
| 需求 | 四族声明 + **来源标注**（自动推算 / 读取 / 声明）+ 允许覆盖 | 恒可用 | 显示推算依据（如"按 GGUF 大小 + ctx 推算"） |
| 策略 | 启用 / 随应用启动 / 归属组（多选）/ 独占 | 恒可用 | 归属组多选时提示共享语义 |
| 底部动作 | 保存 · 准备 · 试运行 · 导出 · 删除 | 保存：有改动；试运行：字段校验通过 | 试运行 = 临时实例；成功后提供「转为持久服务」 |

**运行页**

| 元素 | 可用条件 | 行为 |
|---|---|---|
| 状态区 | 恒可见 | `state` + 就绪结果 + pid/容器 + 端口 + 实测资源 + 最近一次 Run 摘要 |
| 启动 / 停止 / 重启 | 按 `state`；未准备时启动键变为「准备」 | 就地 |
| 强制停止 | 状态为 `starting`/`restarting` 超过阈值，或存在残留 | 确认后清残留 |
| 日志区 | 恒可用 | 尾部 + 打开目录 + 清空 + 自动刷新开关 |
| 记录区 | 恒可用 | Run 列表 + Event 时间线 |

### 2.3 A3 组定义

| 元素 | 可用条件 | 行为 |
|---|---|---|
| 组名 | 必填；重名时提示 | — |
| 成员多选（可搜索） | 存在可选服务 | 勾选加入 |
| 已选成员列表 + 上移/下移/移除 | 成员 ≥2 时可排序 | 顺序即启动与停止序，需在界面上说明这一点 |
| 独占开关 | 恒可用 | 说明会与哪些独占组互斥 |
| 随应用启动 | 恒可用 | — |
| 保存 / 删除 | 删除为危险动作 | 删除文案：**只解散组合，不删除任何服务** |

### 2.4 A4 素材

| 元素 | 可用条件 | 行为 |
|---|---|---|
| 素材行（名称/类型/位置/大小/校验/引用数） | 恒可见 | 引用数 > 0 时「删除」禁用并提示"还有 N 个服务在用" |
| 获取 | 未就位或损坏 | 下载 / 拉取 / 定位文件 |
| 校验 | 已就位 | 重算摘要比对 |
| 查看引用 | 引用数 > 0 | 列出引用它的服务 |

### 2.5 A5 设置

| 元素 | 可用条件 | 行为 |
|---|---|---|
| llama 能力三项 | 恒可用 | 扫描根为空时说明"模型面板不会出现" |
| 运行策略三项 | 恒可用 | — |
| 数据位置 | 恒可用 | 打开日志目录；配置路径可复制 |
| 配置快照列表 + 恢复 | 快照 ≥1 | 恢复为危险动作：文案说明"当前配置将被覆盖，操作前会自动生成一份快照" |

## 3. 处置层（就地展开）

| 面 | 元素 | 可用条件 | 行为 |
|---|---|---|---|
| C1 归因 | 族 / 阶段 两行 + 原始错误（可复制） | 恒有 | 「复制错误」 |
| C2 日志 | 尾部 · 打开目录 · 清空 · 自动刷新开关 | 日志文件存在 | 自动刷新仅在可见时进行 |
| C3 记录 | Run 列表（时间/结果/就绪耗时/资源峰值）+ Event 时间线 | 有记录时 | 点 Run 展开当时详情 |
| C4 修正 | 按归因动态给出 1–3 个动作 + 「重试」+「强制停止」 | 动作与其归因匹配 | 执行后就地更新；成功后处置层自动收起 |

**C4 的动态映射**（这是"能修"和"只能看"的分界）：

| 归因 | 给出的动作 |
|---|---|
| 环境缺失（runtime/文件/镜像） | 「去准备」+「定位文件」+「打开设置」 |
| 占用冲突（端口/互斥） | 「停掉占用者」+「换端口（建议值）」 |
| 资源不足 | 「释放（列候选）」+「降需（建议值）」 |
| 参数错误 | 「编辑服务」并聚焦出错字段 |
| 依赖未就绪 | 「先启动依赖」 |
| 就绪超时 | 「查看日志尾部」+「延长等待」+「强制停止」 |
| 运行中崩溃 | 「查看最近 Run」+「重启」+「禁用（阻止反复重启）」 |

## 4. 浮层

| 浮层 | 元素 | 规则 |
|---|---|---|
| Toast | 文本 + 可选「查看」 | 4 秒自动消失；同类连续动作合并；失败 Toast 常驻直到手动关闭 |
| 确认模态 | 标题 + 后果说明 + 确认/取消 | **四类危险动作各有专属文案**（删服务 / 删组 / 强制停止 / 快照回滚） |
| 内联条 | 文本 + 动作 | 外部配置变更（应用/忽略）、资源告警（看占用者）、切换进度（中止） |
| 抽屉 | 标题 + 页签（定义/运行）+ 关闭 | 载入中不清空已有内容；同一时刻只开一个 |

## 5. 尚未覆盖、下次要补的

1. **新建服务的第一步（探测）** 的具体控件与候选形态的呈现方式。
2. **可视化参数面板**（llama 那套 ctx/ngl/cache 等）与"高级模式原始参数"的往返，在新结构下的归属。
3. **搜索/过滤的作用域**：是跨面统一，还是每个面各自一份。
4. **键盘与无障碍**：焦点顺序、快捷键（启动/停止/刷新）、`prefers-reduced-motion`。
5. **窗口与托盘菜单**：托盘右键菜单项（打开主界面 / 快速启用某组 / 退出）与主界面的关系。
