# 服务中枢 · 重塑计划（目标与里程碑）

> 本文件是「按 Carbon 视觉语言重塑产品」的**最终目标与验收定义**。
> 上游依据：[ui-layout.md](ui-layout.md)（容器清单与三页布局）、[behavior-map.md](behavior-map.md)（55 项行为 / 18 个闭环）、
> [preview/README.md](preview/README.md)（视觉语言的落地与验收工具）。
> 视觉语言来源：`design-md-library` → `ibm/DESIGN.md`（Carbon Design System）。

## 最终目标（用户口径）

**最终产品的展现与功能，与 `ui-l2-carbon.html` 所展现的一致。**

也就是说：不是「把 Carbon 涂在旧结构上」，而是把 L2 预览里的产品表面**在真实应用里逐一做实**。
预览里那些「预览载体」（场景切换、视图切换、浮层直达按钮、标注模式开关）**不属于产品，不实现**；
产品自己的面（四个视图、五个模态、抽屉、Toast、内联条）必须一致。

Carbon 的视觉规则与 ui-layout.md 的三态结构是同一件事的两面：规则保证它像那套设计语言，结构保证它装得下 55 项行为。

## 完成定义（Definition of Done）

1. **面齐**：ui-layout.md 容器清单里的面在真实应用中存在且可达（3 个一级面 + 1 个二级面 + 5 个模态 + 1 个抽屉 + Toast + 内联条）。
2. **门槛绿**：每个里程碑都通过 `typecheck`、全部单测、`build:renderer`、以及**真实渲染探针**。
3. **Carbon 不变式**：0px 圆角（唯一的 2px 例外是极小的角标）、卡片无投影（仅浮层可用 `--elev-panel`）、
   蓝色稀缺（只在主 CTA / 选中 / 焦点 / 进度）、无全大写标签、无渐变、无玻璃。
4. **可访问性**：交互控件边界对比度 ≥ 3:1（WCAG 1.4.11）；文字 ≥ 4.5:1。
5. **不破坏既有功能**：启停 / 重启 / 编辑 / 日志 / 设置 / 预设 / 下载全部可用，88 项单测继续通过。

## 工程约定（每个里程碑都要遵守）

1. **改样式不改结构**优先：TSX 里不写 `var(--*)` 与内联色值，样式全部走 `styles.css` 的命名令牌。
2. 真实性优先：**不编造数据**。账本里的每个数字都来自主进程；推算值必须标注"推算"。
3. 每次改完跑 `scripts/shot-renderer.ps1 -Probe`：它给内置 API 打桩、渲染构建产物、断言 DOM 结构与 Carbon 不变式。
   Chrome 在 `file://` 下会因 CORS 拒绝 ES module（页面纯白），所以工具走本机 HTTP。
