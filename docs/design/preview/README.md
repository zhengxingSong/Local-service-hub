# 结构预览（可交互）

[ui-preview.html](ui-preview.html) —— 单文件、离线可开，按真实窗口尺寸 1120 × 780 渲染。

**这是结构预览，不是视觉方案。** 颜色与字体都还没定；它回答的是：三态各有什么面、控件长在哪里、一个按钮在什么条件下才亮、以及它牵动谁。

## 怎么用

| 操作 | 效果 |
|---|---|
| 右上角三个标签 | 在 **运行态 / 配置态 / 处置态** 之间切换 |
| 悬停任意虚线框控件 | 右侧显示该控件的 **功能 / 可用条件 / 关联控件** |
| 悬停时 | 关联控件被紫色高亮（看清一个动作牵动哪些东西） |
| 点击控件 | 固定说明；再点别处或按 `Esc` 取消 |
| 「显示控件标注」 | 一次点亮全部 102 个可交互控件并编号 |
| 处置态左上角 | 切换「预检不通过（模态）」与「运行异常处置（就地展开）」两种形态 |

## 覆盖范围

- **运行态**：用途卡（部分可用 / 未运行 / 单成员 / 切换中四种形态）· 成员明细就地展开 · 资源面（余量 + 可启动清单 + 占用者与可信度标注）· 切换进度
- **配置态**：服务清单（定义视角 + 三个状态位徽标）· 服务抽屉（定义页六段：形态 / 准备 / 启动 / 暴露与就绪 / 需求 / 策略）
- **处置态**：预检决策面（四族 + 三条出口 + 强制启动）· 运行异常处置层（归因 / 日志 / 记录 / 修正）
- **标注**：102 个控件，各自带功能、可用条件、关联控件

## 尚未画进来

新建服务的第一步（探测）· 可视化参数面板与原始参数往返 · 组定义模态 · 设置页（含配置快照回滚）· 退出确认模态 · Toast · 素材面 · 切换失败的回滚过程。

## 维护约定

1. 每个可交互控件都要写三个属性：`data-fn`（功能）、`data-cond`（可用条件）、`data-rel`（关联控件的 `data-id` 列表）。**可用条件是一等内容**，不许留空或写"未声明"。
2. 关联目标写在 `data-id` 上即可，脚本会同时按 `id` 与 `data-id` 查找。
3. 改完做一次自查（静态引用 + 无头浏览器解析）：

```powershell
# 悬空引用、重复 id、div 配平、外链
node <check-script>.mjs ui-preview.html
# 解析 + 脚本执行是否完整（角标数应等于"可承载子元素的 data-fn 元素数"）
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu --dump-dom `
  "file:///D:/LLM%20Model/llama.cpp/desktop/docs/design/preview/ui-preview.html" > dump.html
```

4. `<table>` / `<input>` / `<select>` 上可以挂 `data-fn`（悬停高亮照常生效），但角标不会注入——它们不能承载子元素。
