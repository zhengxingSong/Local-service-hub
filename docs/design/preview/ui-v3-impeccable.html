控件标注 悬停
这一版是什么
按 docs/design/ui-layout.md 的容器清单与 behavior-map.md 的 55 项行为做出的重新设计版高精度预览： 视觉世界换成「量灯台架」，产品事实、内容、功能与真实数据全部保留。

哪里不同
反参照是 ui-preview.html 的石墨底 / 电光蓝 / 圆角卡片 / 发光徽标。这一版是浅底搪瓷灰、刻蚀分隔线、方孔量灯、带刻度的量程条 —— 面板靠线分层而非投影，强调靠字重而非颜色，状态只由语义色表达。

怎么用
· 顶部三组开关：场景（真实 / 排障 / 切换）、视图（运行 / 配置 / 服务编辑 / 设置）、浮层（预检 / 危险确认 / 素材获取 / 探测 / 组编辑 / 服务抽屉）
· 可走通的链路 9：点「聊天组 → 启用」→ 预检（占用族冲突 + 资源族差 4.1 GB）→ 点「停掉它」→ 模态关闭、场景切到切换演示、OpenViking 组进入「停止中 2/4」
· 打开「标注模式」后悬停控件：这里显示功能 / 可用条件 / 关联控件，关联控件同时高亮；点击可固定，Esc 取消
标注模式下，控件必须同时挂三个属性：data-fn（功能）/ data-cond（可用条件）/ data-rel（关联控件的 data-id）。可用条件是一等内容，不留空、不写「未声明」。
